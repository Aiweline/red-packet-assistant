# 隐私说明

[English](../PRIVACY.md) | [简体中文](PRIVACY.zh-CN.md)

红包助手按本地运行原则设计。上游项目不包含分析统计 SDK、广告 SDK、账号系统、远程 API 客户端或遥测端点。

## 各平台访问的数据

### Android

- 通知监听服务接收微信包名（`com.tencent.mm`）发布的通知标题和正文，并使用少量红包关键词进行匹配。
- 无障碍服务被限制为只处理微信包名，并读取系统公开的控件文本、描述、状态和位置，以查找固定规则下的红包动作。
- Android 本地偏好设置保存自动化开关、发现/尝试计数、最近动作说明和时间戳。

通知和辅助功能内容只在设备本地即时匹配。上游应用不会持久化消息正文、联系人姓名、聊天记录或完整辅助功能树。

### macOS

用户授予辅助功能和屏幕录制权限后，应用读取运行中微信进程向系统公开的辅助功能标签和控件元数据。如果这些标签不足，应用通过 ScreenCaptureKit 截取当前可见的微信窗口，并在内存中使用 Apple Vision OCR 本地识别。截图不会保存、保留或上传；匹配和计数只存在于本地应用进程，也不会上传。

### Windows

应用读取可见微信窗口控件的 UI Automation 名称和位置。当某个微信版本只把自绘聊天画布暴露成少量 UIA 元素时，应用通过 Windows GDI 捕获当前可见的微信窗口，并在本地内存中判断红包卡片的颜色和形状。捕获像素不会保存、保留或上传；匹配和计数只存在于本地应用进程，也不会上传。

### iOS / iPadOS

上游应用不请求跨应用数据权限，也不实现跨应用自动化。

## 网络使用

应用代码不包含网络客户端，也不传输用户数据。构建项目所使用的 Flutter 或平台开发工具可能有各自的可选诊断功能，但它们不属于运行中的应用。

## 权限与控制

自动化默认关闭。Android 在跳转通知或无障碍系统设置前展示独立披露。用户可随时关闭应用内开关，或在操作系统中撤销权限。

## 第三方构建

Fork 或重新分发的版本可能改变上述行为。安装第三方构建前，请检查准确源码和分发者的隐私政策。

## 隐私问题

请勿在公开 Issue 中发布通知内容、聊天截图、联系人姓名或其他个人数据。敏感报告请使用仓库 **Security** 页面中的 GitHub 私密漏洞报告流程。
