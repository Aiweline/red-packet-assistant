# 安全政策

[English](../SECURITY.md) | [简体中文](SECURITY.zh-CN.md)

## 报告漏洞

请使用仓库 **Security** 页面中的 GitHub 私密漏洞报告流程。修复发布前请勿公开披露漏洞，报告中也不得包含真实聊天内容、通知负载、账号凭据、联系人数据或签名密钥。

请包含以下信息：

- 受影响平台和操作系统版本；
- 应用提交版本或发布版本；
- 微信版本；
- 使用合成数据的最小复现步骤；
- 预期行为和实际行为；
- 你对用户影响的评估。

## 安全边界

上游项目不得：

- 请求或保存微信账号凭据；
- 访问微信聊天数据库；
- 上传通知或辅助功能内容；
- 向微信注入代码或修改其二进制文件；
- 绕过操作系统安全控制、私有 API 限制、越狱保护或权限提示；
- 在版本控制中包含 keystore、证书、令牌、Cookie 或其他凭据。

自动化必须默认关闭、经过权限控制、采用固定规则、严格限定于红包标记，并可由用户立即停止。

## 受支持源码

安全修复只面向最新默认分支。非官方 Fork 或第三方分发者提供的二进制文件不在上游项目的信任边界内。
